# Zombie Game 🧟

A Unity 3D first-person survival game. Navigate a dark maze, collect keys, find the correct house to escape — all while avoiding zombies hunting you down.

## Gameplay

- First-person perspective survival game
- Explore a dark maze-like environment
- Collect keys scattered across the map
- Find the correct house to escape
- Avoid zombies — getting caught damages your health

## Controls

| Key | Action |
|-----|--------|
| WASD | Move |
| Mouse | Look Around |
| Space | Jump |
